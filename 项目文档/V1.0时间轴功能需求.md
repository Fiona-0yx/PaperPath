# V1.0 时间轴功能需求调整

## 一、功能定位

时间轴位于**学习画像页面**中，作为一个独立标签页。

时间轴定位为用户的**长期学习历程记录**，主要展示：

1.  用户阅读过哪些论文。
2.  用户的学习画像发生了什么变化。

时间轴不用于展示每一次具体操作，也不作为详细行为日志。

## 二、时间轴展示内容

时间轴只展示两类核心事件。

### 1. 论文阅读记录

记录用户的论文阅读经历，包含：

-   论文名称
-   开始阅读时间
-   最近阅读时间
-   阅读进度或阅读状态
-   对应论文的查看入口

### 2. 学习画像更新记录

记录学习画像发生的变化，包含：

-   新增了什么画像内容
-   修改了什么画像内容
-   哪些问题已经得到解决
-   画像更新时间
-   更新所依据的学习行为
-   必要时展示更新前后的变化

## 三、页面展示方式

建议按时间倒序排列，并按照日期分组。

示例：

### 2026年11月27日

**论文阅读 · 10:00**

深度学习中的注意力机制

-   阅读第一、二章
-   阅读状态：进行中

**画像更新 · 11:30**

当前学习困难

-   新增：注意力机制相关概念需要进一步理解

### 2026年11月26日

**论文阅读 · 14:00**

Transformer 架构研究

-   阅读状态：已完成

**画像更新 · 16:20**

知识理解情况

-   某些 Transformer 基础概念由"待理解"更新为"已理解"

以上内容仅为界面示例，实际记录应来自用户真实行为和画像数据。

## 四、筛选功能

时间轴提供三个筛选选项：

-   **全部：** 展示所有论文阅读和画像更新记录。
-   **论文阅读：** 只展示论文阅读记录。
-   **画像更新：** 只展示学习画像变化记录。

## 五、数据记录规则

系统需要区分两个数据层次：

  数据层         记录内容                                    是否在时间轴展示
  -------------- ------------------------------------------- ------------------
  详细行为记录   划线、修改颜色、取消划线、收藏、AI 提问等   否
  学习历程记录   论文阅读事件、学习画像更新事件              是

例如，用户一天内对同一篇论文进行了 20 次划线和 5
次提问，时间轴不应因此出现 25 条操作记录。

时间轴只展示论文阅读事件，以及实际发生的学习画像更新事件。

详细行为记录仍需保留，供学习画像分析和追溯更新依据使用。

## 六、功能验收标准

-   [ ] 时间轴位于学习画像页面中，作为独立标签页。
-   [ ] 能够记录用户阅读过的论文。
-   [ ] 能够展示论文阅读时间及阅读状态。
-   [ ] 能够记录学习画像新增、修改和解决的问题。
-   [ ] 能够展示画像更新时间和更新依据。
-   [ ] 所有记录按照时间倒序排列。
-   [ ] 支持全部、论文阅读、画像更新三种筛选。
-   [ ] 划线、收藏、AI 提问等细粒度操作不直接显示在时间轴中。
-   [ ] 时间轴记录能够关联真实论文和画像数据。

## 七、与其他模块的关系

  模块       职责
  ---------- ------------------------------------
  行为记录   收集用户划线、收藏、提问等详细操作
  学习画像   分析行为数据，整理用户的学习情况
  时间轴     展示论文阅读经历和学习画像变化

三个模块各司其职：

**行为记录负责收集数据，学习画像负责理解数据，时间轴负责展示学习历程。**

## 八、V1.0 最终需求

时间轴位于学习画像页面中，作为一个独立标签页。

仅展示两类事件：

1.  **论文阅读：** 记录用户阅读过的论文、阅读时间及阅读状态。
2.  **画像更新：** 记录学习画像新增、修改、解决的内容，以及更新依据。

支持按时间倒序排列，并按照事件类型筛选。

划线、收藏、AI 提问等细节只进入后台行为记录，不直接显示在时间轴上。

**核心原则：时间轴展示宏观学习历程，不展示琐碎操作日志。**
