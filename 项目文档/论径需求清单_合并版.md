## 怎么使用这份清单

1. **每次只喂两块**：第 0 部分（通用约定）＋ 当次要做的那一个部分。其余不用喂。
2. **一次只做一个部分**，顺序见第 10 部分。
3. 让 AI **先复述**它理解的任务、打算动哪些文件，你确认后再让它改。
4. 做完对照该部分末尾的「验收」逐条检查，通过后再 `git commit`。
5. 标了 **【待确认】** 的内容，AI 不得自行决定，必须先来问你。

**标注含义**
- **【已确认】**：你明确说过的要求。
- **【待确认】**：还没定，需要你拍板。
- **【建议】**：整理时补充的建议，没有经过你确认，不同意可以删。

# 第 0 部分　通用约定（每次都要喂）

## 0.1 产品是什么

论径：面向本科生的自适应文献学习智能体。围绕用户**具体的目标、基础和答题证据**来组织论文学习，闭环是「诊断 → 选文 → 带读 → 反馈 → 沉淀」。

## 0.2 本次做什么、不做什么

- **做**：完整的前端演示，主流程从头跑到尾；可使用假资料、虚构论文、模拟服务；同时有与前端功能相匹配的基础代码框架。【已确认】
- **不做**：真实大模型接入、真实文献检索、PDF 解析、账号与数据库、原生 iPad App。
- 模型提供方、具体型号、各步骤用哪个模型**都还没定**。Codex 只是开发工具，不代表运行时用某个厂商。【已确认】

## 0.3 四份原版源码（底座与素材）

| 参考作品 | 原始位置 | 承担的角色 |
| --- | --- | --- |
| Sylva / Living Green | `sylva-preview`，参考文件 `inner-green-3d.html` | 首页、学习花园、藤蔓路径、分支入口 |
| CompleteShelf | `complete-shelf-preview`，参考文件 `complete-shelf-v2.html` | 论文书架、切书、选书、抽出、开书 |
| Meng To Sketchbook | `sketchbook-preview/public/landing-pages/meng-to-sketchbook.html` | 自我介绍、动态问答、读前/读后测试 |
| Bestsellers Book Showcase | `book-showcase-preview`，参考文件 `bestsellers-book-showcase.html` | 书籍装帧与纸页细节，统一书籍外观 |

**复用规则（最重要）【已确认】**
1. **直接使用原版源码**，保留它的视觉、材质、布局和动画，只为业务做必要修改。
2. 不能只借素材另做一套页面，再说成"复用了"。
3. 每次交付时，AI 必须说明：**保留了原版哪些代码、改了哪些、没复用哪些**。
4. 视觉判断以**原始源码和你给的截图**为基准，不以 AI 之前做的版本为基准。
5. 你认可的是"原始参考"，不等于认可"改造后的版本"。

## 0.4 整体气质

- 植物手账风格。**不要非常硬朗的科技风，线条要柔和**。【已确认】
- 不接受把参考作品改成普通宣传页或通用卡片后台。
- 不在藤蔓上盖大面积米白遮罩。植物场景本身（苔藓、藤蔓、花粉、蝴蝶、浮动卡片）是首页主角；纸张、插画、装帧主要用在书本内部和信息承载页面。
- 书架保留原版背景（随选中的书变色，沿用原版的变换样式）、横向排列、实体书质感，**不要改成白底卡片列表**。【已确认】
- "统一"主要体现在：文案、品牌、材质关系、导航连续性，而不是把四套页面刷成同一个样子。
- 要保留一份代码里面的页面交互和页面转化时的丝滑操作，当需要连接两个不同页面的代码时。页面变换样式仿照下一个页面的交互操作。

## 0.5 内容层级【已确认】

```
一个学习方向
 └─ 藤蔓分支（沿藤蔓探索；现为五个主题分类，见第 1 部分）
     └─ 每个分支一个书架
         └─ 一篇论文 = 一本书
             └─ 四个学习阶段：开始检测 / 论文阅读 / 最终检测 / 人物画像成长
```

## 0.6 语言规则【已确认】

不论哪种界面语言，**论文都不改语言**。

| 内容 | 中文模式 | 英文模式 |
| --- | --- | --- |
| 导航、按钮、提示、表单 | 中文 | 英文 |
| 提问、反馈、辅助带读 | 中文 | 英文 |
| 大分支标题 | 中文主标题，可带小号英文副标题 | 英文 |
| 论文标题、摘要、正文、原文引文 | 保持原语言 | 保持原语言 |
| 用户自己填的原话 | 保留原话 | 保留原话 |

**【已确认】**：`FIELD NOTES`、`Every question is a small beginning.` 这类固定英文装饰文案，哪些保留为品牌标识、哪些要本地化。

## 0.7 内容与数据规则【已确认】

- 论文、作者、实验数字都是**虚构教学材料**，要标注，不放真实 DOI，不包装成真实检索结果。
- 画像里的信息分三类并标注来源：**用户自述 / 答题证据 / 系统推测**。
- 没提到的记为**未知**，不当作"不会"。
- 一两道题只支持**局部**判断，不推断整个领域水平。例如写"能识别训练集与测试集的作用；数据泄漏概念尚未确认"，不写"机器学习水平中等"。
- 开放回答不能因为没匹配选项就判错。
- 新用户不带任何捏造的学习成绩。

## 0.8 工作方式规则【已确认 / 建议】

- 先说方案，经你确认再改代码。【已确认】
- **新设计的页面，必须先展示给你看，确认后再实现。** 复用原版的要求优先，不能借"新设计"另做一套替代原版。【已确认】
- 一次只改当前部分涉及的内容，不顺手"优化"其他地方。【建议】
- 拿不准的地方先问，不自己猜。【建议】
- 每完成一块先 git 提交，不满意就退回，不在坏的基础上继续叠加。【建议】

## 0.9 技术栈

- 原生 HTML / CSS / JavaScript（ES Modules）＋ Three.js，不引入 React、Vue 等框架。理由：四份原版都是这种形式，沿用最省事。
- Node.js 原生 HTTP 服务：提供静态文件和模拟 JSON 接口，不需要安装 npm 依赖。
- hash 路由组织页面；藤蔓和书架可放在同源 iframe 中运行，用消息传递交换"语言、分支、书目、完成状态、点击事件"。
- 用户状态由主应用**统一管理**，不让每个参考页面各自维护一套进度。

## 0.10 统一术语【建议】

方向、分支、书架、论文（书）、阶段、画像、证据、旁注、理解检查、成长。同一件事全站只用一个名字。

# 第 2 部分　手账入口与画像采集（固定题）

**底座**：Sketchbook 原版（`sketchbook-preview/public/landing-pages/meng-to-sketchbook.html`）

## 目标
用原版手账承载开始阶段的自由介绍、逐页画像采集，以及论文学习中的**读前测试和读后测试**。当前先把入口和书架主流程做通；动态问答之后再做，不作为当前入口的完成条件。【已确认】

## 必须做到：复用原版手账【已确认，最高优先】
- **直接使用原版源码**，保留它的书本外观、弯曲卷页、光影、前后翻页交互。
- **只替换内容**。原版书页主要是图片，需要适配成可选择、可输入的测试内容，但**不能用自制的静态表单代替原版**。
- 之前做过的自制左右双栏 notebook（只借了植物素材、切题时轻微旋转淡入）**不算**满足这条。
- 书本尺寸可以调整，但调整方案**必须先给你确认**。
- 背景可以保持原版，需要符合整体风格。

## 采集题的作答与翻页【改进需求，待实现】
- 移除题目下方的「记下回答」。选中、改选、填写「其他」时自动记录当前答案。返回原页或刷新后，仍能看到最后一次作答。普通采集题只记录自述，小自检只判断对应概念。
- 题目之间可以自由前后翻。查看画像时统一检查漏答。主动点过「跳过 / 不确定」的题记为未知，已从自我介绍明确取得答案的字段也无需补答。「其他」只填空格或清空所有选择时，按未答处理。
- **翻页连续性**：起翻的第一帧要与用户刚看到的书页一致，包括题干、选中项、输入文字和按钮。翻动中，文字与控件随所属纸面移动，已露出的对页保持稳定。落页的最后一帧与停稳后的可操作书页应在同一位置显示相同内容。验收时分别慢拖、点箭头前后翻，并检查自动翻页；起翻和落页时都不应闪白、闪回上一题或突然换字、跳位。

## 入口流程【已确认】
1. 首页点**「开始」**，以按钮中心为圆心，向四周展开一个圆形窗口。圆内逐渐露出手账的纸色背景和摊开的书，圆外仍能看到藤蔓首页，直到圆覆盖整个视口。转场结束时，书保持摊开在古树与压叶扉页。
2. 用户用原版翻页交互翻过扉页，进入自由介绍题。十页采集从这道题开始计数。
3. 后续按下表采集，每一面承载一个主问题，摊开的左右两面可各显示一题。已明确的信息可以跳过。
4. 最后一页（封底）展示**可直接修改的画像小结**，每个字段带来源和把握度，详见第 3 部分。
5. 已有采集或学习记录时，首页按钮变为**「继续」**，直接回到上次位置。采集中断要能回到手账相应页，学习中断要能回到相应学习位置。

## 入口扉页：古树与压叶【构图与题字已确认】

- 采用用户指定的 Sketchbook 古树跨页。左页保留原版水彩古树和延伸过书脊的树冠；右页保留胶带固定的棕色压叶、纸纹和阴影。压叶比参考图略小，给下方题字留出空间。
- 在右页右下方、叶片下方原英文手记的位置写 **「用户初始画像采集」**。
- 题字暂选**霞鹜文楷（常规字重）**，以暖棕色墨迹呈现。字体与叶片最终大小由用户看过扉页效果后确认。

## 采集第 1 页：自由表达【已确认方向，以下为采用文案】

> **最近有什么想弄明白的东西，或者想读的方向？**
> 一句话就行。

# 第 5 部分　书内的四个学习阶段

## 目标
一本书里依次完成：开始检测 → 论文阅读 → 最终检测 → 人物画像成长。

| 阶段 | 承载的信息 | 说明 |
| --- | --- | --- |
| 开始检测 | 相关片段、读前问题、回答及依据 | 使用第 2 部分的原版手账 |
| 论文阅读 | 原文、目录、术语、带读、疑问、旁注 | 阅读工作台 |
| 最终检测 | 检查是否理解本篇关键内容，给出原文反馈 | 使用原版手账 |
| 人物画像成长 | 本篇收获、未确认项、下一步建议，更新总画像 | 本篇成长页 |

## 论文阅读【已确认】
- **原文优先可读**，辅助讲解与当前段落相关。
- 点击引用能定位到原材料。
- 论文原文始终保持原语言。

## 检测
- 可跳过；开放回答保持"待确认"，不伪造评分。
- 内容要有材料依据，答题证据要能真实改变后续安排。

## 带读与 Critic（首版）
- 解释和引用对应预置材料。
- Critic 目前只做规则检查（引用的句子是否出自当前材料），**不能说成已经做了语义事实核验**。
- 只有摘要时，只围绕摘要出题；方法、实验细节、逐节带读需要正文。PDF 解析暂不接入。

## 【待确认】
你设想"每个书页代表不同环节"。目前实现是路由切换，不是真翻页。四个阶段做成**真实翻页**还是**书签式章节入口**，需要你定。

## 验收
- [ ] 四个阶段都能进入，顺序合理
- [ ] 阅读页点引用能定位到原文
- [ ] 检测能跳过，开放回答不会被判错
- [ ] 完成后本篇状态更新为已完成
