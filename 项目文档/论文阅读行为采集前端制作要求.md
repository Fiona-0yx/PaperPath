# 论径 · 论文阅读行为采集前端制作要求

## 一、交付目标

在现有论文阅读页完成一次可回看的阅读过程。读者能选中原文提出疑问，离开该段继续阅读，再从手记返回原句。前端能据此回答三个问题：哪些段落在屏幕上可见、读者主动标记了哪里、读者通过什么操作返回了哪里。

首版用《净辐射模拟与参考作物蒸散量估算》和《理解自注意力机制》验收。首页「开始」仍进入已有的初始画像手账，论文卡片进入阅读页。个性化阅读方案和读前测试作为独立需求排期。

## 二、页面与交互

| 位置 | 制作要求 |
|---|---|
| 左侧论文正文 | 白底，独立纵向滚动。每个正文段落有稳定标识。桌面拖选、手机长按选中文字后，在选区附近出现「记疑问」「问 AI」。保留系统复制操作。点击空白或按 Esc 收起菜单。键盘用户可从当前段落旁的操作按钮使用相同功能。 |
| 中间导航栏 | 沿用现有正文与导航约 4:1 的比例。上方推荐文章，下方章节目录。滚动时高亮当前章节，点目录只移动正文。切换论文时结算上一篇的可见时间。 |
| 最右侧问答与手记 | 选「记疑问」后显示引用原句、所属章节、输入框和保存按钮。选「问 AI」后将同一引用带入现有问答区。草稿绑定发起时的原文位置，继续滚动不改变引用。取消草稿不创建手记。 |
| 已记问题 | 每条显示问题、原文出处和解决状态。支持返回原文、标记已解决、重新打开。返回后把目标段落滚入视野并短暂高亮原句。已有的章节级手记仍可打开，定位到对应章节。 |
| 手机 | 沿用「正文／文章导航／AI 问答」切换。选中原文发问时进入问答视图；点出处时返回正文并定位。打开键盘、旋转手机和切换面板都应保留草稿。 |

**交互样例。** 读者选中“训练集在八月达到峰值，验证集与测试集在七月达到峰值”，点击「记疑问」，写下“为什么峰值月份不同？”并保存。随后点目录去读「模型评价指标」。再次点击手记里的出处，应回到「净辐射的季节变化」中的这句话。同步失败也应能在本机完成这条路径。

## 三、采集口径

| 行为 | 何时记录 | 关键数据 |
|---|---|---|
| 打开论文 | 正文载入成功 | 本次阅读编号、论文编号、进入时间、入口 |
| 段落可见 | 以左侧正文容器为观察范围。建议首版以“可见高度达到段落高度和阅读区高度中较小值的 50%，且连续满 1 秒”为有效区间；满 1 秒后从最初进入时刻起算 | 段落编号、开始时间、结束时间、可见毫秒数 |
| 切换阅读位置 | 点目录、点问答出处、从手记回看时，记录起点和落点；自然滚动按有效段落区间记录 | 来源、起止章节和段落。一次主动跳转记一次，滚动动画中的中间段落不另算主动跳转 |
| 选中原文 | 选区稳定并弹出操作菜单时记一次；关闭菜单、选择操作分别记录 | 论文、段落范围、选区长度、操作类型。拖动选区过程中不逐帧写记录 |
| 提问与处理 | 提交疑问、发送 AI 问题、解决、重开、返回出处时分别记录 | 事件类型、章节、段落、问题编号、时间。输入框逐字输入不产生行为事件 |

标签页进入后台、正文面板隐藏或离开论文时，立即结算当前可见区间；恢复可见后另开区间。多段同时可见时各自计时，整篇可见总时长取时间区间并集。记录名称使用“可见时长”“回看次数”；理解程度以读者明确作答或标记为依据。

## 四、本地保存与接口对接

1. **稳定定位。** 用论文编号、内容版本、章节编号、段落编号和选区首尾偏移定位原文；跨段选择保存两个端点。排版变化后仍按文本位置回到原句。内容更新导致原句失配时，回到章节并提示“原文已更新”。
2. **先完成本地闭环。** 接续已有手记，新增行为事件单独保存。每次打开论文建立阅读会话，每个事件生成唯一编号。问题保存成功后立即可回看；刷新后仍能恢复。存储不可用时明确提示“仅在本页暂存”。
3. **再接服务端。** 已有 `POST /api/reader/events` 接收单个事件，成功返回 204。现有协议使用 `kind`、`paperId`、`sectionId`、`paragraphIndex`、`noteId` 等字段。联调前需扩展字段白名单以保留事件编号、会话编号、稳定段落编号、时长和跳转起止位置，并按事件编号去重。之后再启用断网排队和重试；收到成功响应后移出队列。
4. **记录控制。** 在阅读页提供「阅读记录」入口，说明所采行为，提供暂停和恢复。暂停期间仍可手动保存手记。默认让问题正文、引用原句留在本机；行为上报使用位置标识和操作类型。使用在线 AI 时，另行说明本次提问将发送哪些内容。
5. **结果核对。** 首版在本机提供本篇记录摘要，可查看各段可见时长、主动回看次数和已解决问题数。现有 `GET /api/reader/summary` 汇总服务端整份日志；展示个人报告前须支持按用户与论文筛选。

## 五、交付验收

| 操作 | 通过条件 |
|---|---|
| 在同一段停留约 5 秒，切到后台 10 秒，再回来看约 5 秒 | 生成两个可见区间，总计约 10 秒；后台时间排除。快速滑过且不足 1 秒的段落不产生有效区间。 |
| 反复拖动调整选区，弹出菜单后取消 | 不生成问题；按一次完整菜单操作核对，不出现连续数十条选区记录。 |
| 在 A 段开始写疑问，滚到 B 段再保存；刷新后从手记点出处 | 草稿和保存结果均绑定 A；回到 A 并高亮原句。另一篇论文看不到这条本篇记录。 |
| 先自然滚回上一节，再通过目录、手记、问答引文各跳一次 | 能区分自然回看和三种主动入口；每次主动操作都能核对起点和落点。 |
| 手机选句提问，再从问答面板返回 | 输入框和发送按钮可见；返回后原句在视口内；问答面板独占屏幕期间正文计时暂停。 |
| 暂停记录、手动记一条问题，然后恢复记录 | 手记保存成功；暂停区间没有自动行为事件，恢复后重新计时。 |
| 接口联调后断网操作，再恢复网络并刷新 | 阅读、写手记和回看均可继续；待同步事件补传，同一事件在服务端只计一次。 |

首版完成的判断标准：在一篇论文中，能够从同一条手记核对**选中的原句、提交疑问时的位置、后来返回原文的动作**，并用可见区间解释段落时长的来源。
