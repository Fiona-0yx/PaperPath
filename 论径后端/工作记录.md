# 论径后端工作记录

## 2026-11-26 · 读前测试与篇内初始画像

目前可以从一份阅读方案出发，为指定论文生成读前测试，接收作答并生成本篇阅读的初始画像。项目中的净辐射论文样例已有 5 道题，测试记录中已保存判分结果和篇内画像。

### 已完成

| 环节 | 完成内容 | 主要文件 |
|---|---|---|
| 阅读方案对接 | 复用已有阅读方案生成器，也支持直接传入上游生成的方案。按本篇的阅读深度、重点和精读步骤选题。 | `plan_generate.py`、`plan_rules.py`、`pretest_cli.py` |
| 生成读前测试 | 第一次调用模型，根据论文元数据和阅读目标提取候选概念。规则去重并优先覆盖重点和精读步骤。第二次调用模型，结合画像生成单选题。候选不足时补充，题目校验失败时针对缺项重试。 | `pretest.py` |
| 作答与判分 | 学生题面与答案解析分开。提交后按答案键判分，区分答对、答错、主动选择“不确定”和整套跳过，保留题目与阅读步骤的关联。 | `pretest.py`、`pretest_cli.py` |
| 篇内读前画像 | 用本地规则合并原始画像、阅读方案和逐题结果，生成固定结构的 `paper_profile`。答错的概念在首次涉及的步骤安排补讲；主动选“不确定”时提供可选解释。跳过或未启用测试时沿用本篇方案。 | `paper_profile.py` |
| 配置与保存 | 支持在 `llm.local.json` 填写兼容 Chat Completions 的接口地址、模型名和密钥。判分与画像一起保存在本次会话中。旧版会话可在判分时补入原始输入与方案。 | `plan_generate.py`、`pretest_cli.py` |

### 样例与验证

- **样例输入**用 `samples/净辐射_测试输入.json` 提供用户画像与论文题名，用 `samples/净辐射_阅读方案.json` 提供阅读需求。`samples/answers.json` 是本次作答文件。
- **样例输出**保存在 `samples/净辐射_测试记录_01.json`。查看 `grading` 可核对判分，查看 `paper_profile.concept_evidence` 和 `paper_profile.step_support` 可追溯某条补讲建议来自哪道题、用于哪一步。
- **测试结果**：本次运行 `python -m unittest -v`，15 项全部通过。覆盖阅读方案、考点选择、无效模型输出的重试、命令行判分与保存，以及不同完成状态下的画像合并。生成流程的自动化测试使用模拟模型响应。

### 已设计、待实现

1. **基于原文段落选题。** 当前出题使用题名、摘要和章节标题等元数据。后续接入论文 PDF 或上游解析文本后，按阅读重点定位段落，并随考点保存段落编号及可用页码。
2. **基于篇内画像的文章问答。** 用户提问时检索相关原文，再结合对应概念的作答证据决定解释深度。用户当次提出的详略要求优先。

三个业务阶段的输入、输出、算法及命令示例见《读前测试算法与生成流程.md》。不同学科的出题质量与真实阅读效果仍待验证。
