# 净辐射论文 · 读前测试

每题选 A、B、C 或 UNSURE（不确定）。

## q1

某小组用多年历史观测数据训练一个模型来预测土壤湿度，模型内部没有显式写出水分蒸发的物理方程；另一小组则用物理定律建立方程来推算土壤湿度。下列哪项最能说明这两类方法的区别？

- A　前者主要从数据中学习输入与输出的映射关系，后者主要依赖物理规律和方程来描述过程
- B　前者不需要任何观测数据，后者必须使用大量观测数据
- C　前者和经验公式完全一样，后者与经验公式没有任何关系
- UNSURE　不确定

## q2

一个三层人工神经网络接收若干输入特征，隐藏层对输入进行加权组合并通过激活函数变换，最后输出层给出结果。下列哪项正确描述了这类网络的基本组成？

- A　神经元通过对输入加权求和并经过激活函数产生输出，多层连接可形成非线性映射
- B　网络层数越多就一定越准确，因此不需要验证集或测试集
- C　激活函数的主要作用是存储训练数据，输出层负责计算物理方程
- UNSURE　不确定

## q3

地表一方面接收太阳短波辐射，另一方面会反射部分短波并向外放出长波辐射。把地表辐射收支的差额称为净辐射。下列哪项理解最准确？

- A　净辐射是地表辐射收支的净差额，可以为正也可以为负
- B　净辐射就是到达地表的太阳总辐射，不扣除反射和长波支出
- C　净辐射只由土壤水分决定，与短波和长波辐射无关
- UNSURE　不确定
