## 原版复用说明

底座是 `sylva-preview/public/landing-pages/inner-green-3d.html`，原件未改动。`scripts/prepare-grove.mjs` 从原件生成 `public/scenes/grove.html`。

保留原版近景与远景藤蔓、树皮与苔藓着色器、草叶实例、蕨类、小花、花粉、蝴蝶、液态金属按钮、导航交互、入场扫描、卡片照片揭幕和悬浮效果。全景和路径复用相同的五个卡片 DOM；照片来自原版两张 JPG，交替使用。

修改：用原版 `makeLimb` / `assembleRoot` 增建四段有分叉的藤蔓，连接原有根系；改为水平相机路径；两张原生卡片扩为五张，适配尺寸、位置与文字；将卡片圆钮放入卡片右下角；导航减为三个。全景仅切换布局和相机，单个 iframe 在其他页面隐藏保留，返回时不重建场景。

未沿用：原示例生态文案与统计、额外导航项、背景装饰大字、原页面在手机上把卡片照片缩成侧边小图的布局。未引入其他三套参考作品的新改造，未调整旧测评、论文正文或难度分支数据。
